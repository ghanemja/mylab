# Celsius to Fahrenheit

Write a function

```matlab
f = c2f(c)
```

that converts temperatures from degrees Celsius to degrees Fahrenheit.

To convert, multiply by 9/5 and then add 32.

- `c` may be a single number, a vector or a matrix.
- `f` must have the same size as `c`, with every element converted.

## Examples

```matlab
>> c2f(100)
ans =
   212

>> c2f([0 37 -40])
ans =
   32.0000   98.6000  -40.0000
```
