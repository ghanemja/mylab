    Keyboard shortcuts
    
      
    
        
    Ctrl+EnterRun the current file
    
        
    Ctrl+Shift+EnterRun the selection (or the current line)
    
        
    Ctrl+SSave now (files also save automatically)
    
        
    Ctrl+/Comment or uncomment lines
    
        
    Ctrl+SpaceComplete a name (editor)
    
        
    TabComplete a name (command window)
    
        
    ↑ / ↓Previous / next command (command window)
    
        
    Shift+EnterNew line in the command window
    
        
    Alt+NNew file
    
        
    Ctrl+LFocus the command window
    
        
    Ctrl+EFocus the editor
    
      
    
      
    On a Mac, use ⌘ instead of Ctrl.
    
      
    
    
      

  
    
    
      
     About mylab
    
      
    mylab is a free, open-source environment for running MATLAB-language code. This web version runs
        the mylab interpreter (written in Python on NumPy, SciPy and Matplotlib) entirely in your browser
        using Pyodide. Your code and files never leave your computer,
        unless you choose to use an online AI assistant.

    Get a key at console.anthropic.com. Requests go directly from your browser to Anthropic.
    
      
    

      
    
        
        
        
        
    Works with OpenAI, OpenRouter, Groq, Together, LM Studio and other servers that offer
          /chat/completions. The server must allow requests from web pages (CORS).
    
      
    

      
    
        Your key stays in this browser. It is saved in this browser's local storage and sent only to the provider you
        picked, never to mylab. Anyone who uses this browser profile can read it, so do not save a key on a shared or public computer.
        
      
    
      
    With an online provider, your current file, your last error and the names and sizes of your variables are sent with each question.
