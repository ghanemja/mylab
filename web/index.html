     Welcome to mylab
    
      
    Run MATLAB-language code right here in your browser. Free, nothing to install, no account. Pick a place to start:
    
      
    
        
        
        
        
      
    
      
    You can also drop your own files or a folder onto the page. Find this again under “Getting started” at the bottom of the page.
    
      
    
    
      

  
    
    
      
     Share a link
    
      
    The link contains the code itself. Nothing is uploaded: whoever opens the link gets a copy in their own browser and can run it.
    
      
    
        
        
      
    
      
      
      
    
      
    
        This link is long. Some chat and e-mail programs cut off links over about 8,000 characters. For bigger projects, put the files in a public
        GitHub repository and share a link like …#gh=owner/repository instead (Project menu → Open from GitHub).
      
    
      
    
      
        
        
      
    
    
      

  
    
    
      
     Open from GitHub
    
      
    Paste the address of a public repository, or of a folder inside one. mylab downloads its .m files and data files
        (.csv, .txt, .json, .md, .png, .jpg, .mat) into a new project in this browser.
    
      
      
      
    
      
    
      
    Tip for teachers: the link …#gh=owner/repository/folder opens a course repository in one click.

       About mylab
      
      
      mylab is a free, open-source environment for running MATLAB-language code. This web version runs
        the mylab interpreter (written in Python on NumPy, SciPy and Matplotlib) entirely in your browser
        using Pyodide. Your code and files never leave your computer,
        unless you choose to use an online AI assistant.

      Assistant settings
      
      
      The assistant is optional. mylab works fully without it.
      
      

      
      
        
        
        
      
        
      
          
      Ollama runs AI models on your own computer, for free. Install it from ollama.com, download a model
            (for example ollama pull qwen2.5-coder), then start it so this page is allowed to talk to it:
      
          
      
          
      On Windows (PowerShell): . If Ollama is already running as an app, quit it first.
      
        
      
      
      

      
      
        
        
        
      Get a key at console.anthropic.com. Requests go directly from your browser to Anthropic.
      
      
      

      
      
        
        
        
        
      Works with OpenAI, OpenRouter, Groq, Together, LM Studio and other servers that offer
          /chat/completions. The server must allow requests from web pages (CORS).
      
      
      

      
      
        Your key stays in this browser. It is saved in this browser's local storage and sent only to the provider you
        picked, never to mylab. Anyone who uses this browser profile can read it, so do not save a key on a shared or public computer.
        
      
      
      
      With an online provider, your current file, your last error and the names and sizes of your variables are sent with each question.
